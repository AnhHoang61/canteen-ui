# ListRow

Dòng trong thẻ trắng: tiêu đề đậm, giá trị xám bên dưới, chevron khi bấm được, icon xanh đầu dòng tùy chọn.

- `title`, `value`, `icon`, `chevron`, `onClick`, `note` + `noteTone` (`warn` | `danger` | `info`), `trailing`, `children`.
- Đặt nhiều dòng trong `<div class="cp-card">`; các dòng tự kẻ `line` ở giữa.
- Dùng cho chọn Canteen/quầy/ca, phạm vi quyền, thông tin đơn.
