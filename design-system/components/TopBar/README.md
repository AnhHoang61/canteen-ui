# TopBar

Thanh trên cùng của mọi màn hình sau khi mở ca: Canteen, quầy, ca, trạng thái mạng, nhân viên.

- `canteen`, `counter`, `shift`, `staff` (chuỗi), `online` (mặc định true), `pending` (số giao dịch chờ đồng bộ khi offline), `right` (nút thêm).
- Luôn hiển thị để mọi đơn có ngữ cảnh NV · quầy · ca.
