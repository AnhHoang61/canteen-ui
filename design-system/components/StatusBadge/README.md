# StatusBadge

Nhãn trạng thái luôn gồm chữ + icon/chấm, không chỉ dựa vào màu.

- `tone`: `success` (check), `warning` (đồng hồ), `danger` (cảnh báo), `info`, `neutral`, `brand`, `accent`.
- `icon` ghi đè icon mặc định; `icon={null}` để dùng chấm tròn.
- Dùng cho trạng thái thanh toán, đơn đặt trước, nhóm món bị chặn, mạng.
