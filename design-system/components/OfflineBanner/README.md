# OfflineBanner

Dải cảnh báo đặt ngay dưới `TopBar` khi mất mạng hoặc đang đồng bộ.

- Offline: `pending`, `qrPending`, `walletLimit` (giới hạn ví offline mỗi giao dịch).
- Đồng bộ: `syncing`, `done`, `pending`, `conflicts` (số xung đột cần xử lý tay).
- Không cho đóng banner tới khi hàng đợi về 0.
